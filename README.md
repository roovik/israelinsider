# Israel Insider

Voices on Israel in one place: writers, podcasters, video creators and public figures. Items link to the creator's own pages.

- Worker: `worker.js` (JSON API, admin routes, hourly feed ingestion), `lib.js` (feed parsing)
- Front end: `public/` (hash routed, no build step)
- Tests: `node test/run.mjs` runs the end to end test. `node test/serve.mjs` serves a local copy with sample data at http://localhost:8787
- Details: see `README.txt`
